# 💎 중장기 투자 추천 시스템 가이드

## 📋 시스템 개요

**StockVibe Pro**의 중장기 투자 추천 기능은 단기 시그널 이상으로 **재무 건전성, 밸류에이션, 시장 모멘텀**을 종합적으로 분석하여 **3~5년 이상 우상향할 수 있는 종목들을 추천**합니다.

### 핵심 특징
- ✅ **재무 기반 분석**: ROE, 영업이익률, 이익 성장률 등
- ✅ **밸류에이션 평가**: PER, PBR 등 적정 가격 판단
- ✅ **모멘텀 분석**: 최근 주가 추세와 수익률
- ✅ **포트폴리오 자동 구성**: 최적의 자산 배분 제시
- ✅ **상세 투자 근거**: 각 종목의 추천 이유 명시

---

## 🎯 분석 방법론

### 1️⃣ 재무 건전성 분석 (40% 가중치)

**평가 지표 (0-100점)**

| 지표 | 우수 기준 | 점수 배분 |
|------|---------|--------|
| **ROE** | 15% 이상 | 최대 25점 |
| **영업이익률** | 10% 이상 | 최대 20점 |
| **PER** | 10-20배 | 최대 25점 |
| **PBR** | 0.5-2.0배 | 최대 20점 |
| **이익 성장률** | 10% 이상 | 최대 10점 |

**시사점**
- 높은 ROE = 자본 효율성 우수 = 배당 지속성 높음
- 영업이익률 = 본업의 경쟁력 반영
- PER/PBR = 저평가 상태인지 판단

### 2️⃣ 밸류에이션 분석 (30% 가중치)

**평가 기준**

| 항목 | 평가 |
|------|------|
| **저PER** (< 15배) | ✅ 상승 여력 큼 |
| **저PBR** (< 1.0배) | ✅ 순자산 대비 저가 |
| **고PER** (> 25배) | ⚠️ 조정 위험 |

**점수 계산**
```
PER 점수 = (기준PER / 실제PER) × 50점
PBR 점수 = (기준PBR / 실제PBR) × 50점
밸류에이션 점수 = (PER 점수 + PBR 점수) / 2
```

### 3️⃣ 모멘텀 분석 (30% 가중치)

**추세 판정**

| 1년 수익률 | 판정 | 점수 |
|-----------|------|------|
| > 20% | 🟢 강상승 | 80-100 |
| 5-20% | 🟡 상승 | 60-80 |
| -5-5% | ⚪ 보합 | 40-60 |
| -20--5% | 🔴 하락 | 20-40 |
| < -20% | 🔴 약세 | 0-20 |

**점수 계산**
```
모멘텀 점수 = min(100, max(0, 50 + (1년수익률 / 2)))
```

### 종합 점수 산출

```
종합점수 = (재무건전성 × 0.40) + (밸류에이션 × 0.30) + (모멘텀 × 0.30)
```

## 📊 UI 가이드

### 🎯 TAB 1: 추천 종목

**기능**
- 추천 종목 수 선택 (5~30개)
- 최소 재무 건전성 점수 필터링
- 자동 분석 및 순위 도출

**결과 표시**
- 📋 추천 종목 순위 테이블
- 📈 종합점수 차트 (색상으로 점수 표현)
- 📊 평가 구성 요소 스택 차트

**활용 팁**
```
최소 점수를 높일수록 → 더 우수한 종목만 선별
최소 점수를 낮출수록 → 더 많은 선택지 확보

추천: 첫 분석은 최소점수 50점으로 시작
```

### 📊 TAB 2: 상세 분석

**종목별 정보**
- 🎯 추천 레벨 (강력 추천 / 추천 / 관심 / 재검토)
- 💰 주요 재무 지표 (ROE, 영업이익률, 성장률)
- 💵 밸류에이션 (PER, PBR)
- 🔮 투자 전망 (자동 생성)
- ✅ 추천 이유 (항목별 정리)

**예시**
```
추천 레벨: 🟢 강력 추천
종합 점수: 82.5/100

💰 재무 지표
- ROE: 18.3% (고수익성)
- 영업이익률: 12.5% (우수 경영효율)
- 이익 성장률: 15.2% (실적 성장세)

💵 밸류에이션
- PER: 12.1배 (저평가)
- PBR: 0.88배 (주가순자산비율 저가)

🔮 투자 전망
- ✅ 강한 수익성 - 안정적인 배당 기대
- 📈 이익 성장세 - 향후 추가 상승 가능성
- 💰 저평가 상태 - 상승 여력 큼
```

### 💰 TAB 3: 포트폴리오 구성

**기능**
1. 총 투자 금액 입력
2. 포트폴리오 구성 종목 수 선택
3. 자동 배분 계산

**구성 방식: 점수 기반 가중치**

```
각 종목의 배분액 = (종목 점수 / 전체 점수의 합) × 총 투자액

예시)
삼성전자 (점수 85) → 34%
SK하이닉스 (점수 78) → 31%
무신사 (점수 62) → 25%
LG전자 (점수 60) → 24%
(자동 재정규화)
```

**결과 표시**
- 📊 배분 비중 파이 차트
- 📈 종목 점수 비교 차트
- 📋 배분액 상세 테이블
- 📊 포트폴리오 통계 (평균점수, 최저점수 등)

```
포트폴리오 종목: 8-10개

```

### 시나리오 3: 밸류 투자자
```
추천 종목 수: 15개
최소 재무 건전성: 55점
포트폴리오 종목: 6-8개

→ 저평가 우량주 중심 구성
```

## 📈 해석 가이드

### 추천 레벨별 의미

| 레벨 | 점수 | 의미 | 투자 성향 |
|------|------|------|---------|
| 🟢 강력 추천 | 80+ | 매우 우수한 투자 기회 | 공격적 |
| 🟡 추천 | 70-79 | 좋은 투자 기회 | 균형적 |
| 🔵 관심 | 50-69 | 모니터링 가치 있음 | 보수적 |
| 🟤 재검토 | -50 | 추가 검토 필요 | 회피 |

### 재무 지표 해석

**ROE (자기자본이익률)**
- 15% 이상: 매우 우수 ✅
- 10-15%: 양호
- 5-10%: 보통
- 5% 미만: 약함 ⚠️

**영업이익률**
- 15% 이상: 매우 강한 경쟁력 ✅
- 10-15%: 우수한 경쟁력
- 5-10%: 평균적 경쟁력
- 5% 미만: 약한 경쟁력 ⚠️

**PER (주가수익배수)**
- 10배 미만: 매우 저평가 ✅
- 10-15배: 저평가
- 15-20배: 적정가
- 20-25배: 고평가
- 25배 초과: 매우 고평가 ⚠️

**PBR (주가순자산비율)**
- 0.5배 미만: 매우 저평가 ✅
- 0.5-1.0배: 저평가
- 1.0-1.5배: 적정가
- 1.5배 초과: 고평가 ⚠️

## ⚠️ 주의사항

1. **과거 실적 ≠ 미래 성과**
   - 재무 지표는 과거 데이터 기반
   - 시장 환경 변화를 반영하지 못할 수 있음

2. **분석 오류 가능성**
   - 데이터 오류 또는 누락
   - 회계 부정행위 등 숨겨진 위험

3. **개별 투자 결정**
   - 본 분석은 참고자료일 뿐 투자 권고가 아님
   - 전문가 자문 후 신중하게 결정

4. **시장 변수**
   - 금리, 환율, 경기 등 매크로 요인 변화
   - 산업군별 사이클 변동

5. **포트폴리오 관리**
   - 정기 리밸런싱 필요 (분기/반기)
   - 잃을 수 있는 금액만 투자

## 🚀 추천 사용 흐름

### 1단계: 초기 분석
```
1. TAB 1에서 "추천 종목 분석" 실행
   - 최소 점수: 50점 (기본값)
   - 추천 종목: 10개 (기본값)
2. 결과 확인 및 상위 5개 종목 체크
```

### 2단계: 상세 검토
```
1. TAB 2에서 각 종목 상세 분석
2. 재무 지표 및 전망 검토
3. 개인 투자관에 맞는지 확인
```

### 3단계: 포트폴리오 구성
```
1. TAB 3에서 투자 금액 입력
2. 자동 배분 결과 확인
3. CSV로 다운로드하여 저장
```

### 4단계: 정기 모니터링
```
- 분기별로 재분석 (데이터 업데이트 후)
- 시장 뉴스 모니터링
- 반기별 리밸런싱 검토
```

## 📊 데이터 요구사항

### 필수 데이터

**재무 데이터** (recent 분)

- date: 공시 날짜

- operating_margin: 영업이익률 (%)

**주가 데이터**
- code: 종목코드

- 재무 데이터: 금융 공시 시스템 (DART)

## 📞 문제 해결

### Q: 분석 중 오류가 발생했어요
**A:** 
1. 데이터가 충분히 로드되었는지 확인
2. "메인 대시보드" → "데이터" 탭에서 데이터 수집
3. 3시간 이후 재시도

### Q: 추천 종목이 너무 적어요
**A:** 최소 재무 건전성 점수를 낮춰보세요
- 60점 → 50점: 더 많은 선택지
- 50점 → 40점: 더욱 다양한 종목

### Q: 왜 이 종목이 추천되지 않았나요?
**A:** 종목별 상세 분석에서 확인
- 재무 점수가 기준 미달?
- 밸류에이션 악화?
- 모멘텀 약화?

### Q: 포트폴리오를 자주 바꿔야 하나요?
**A:** 권장 리밸런싱 주기
- 분기별 1회: 점수 재계산
- 통상 큰 변화 없음: 유지
- 점수 급락 (10점+): 재검토
