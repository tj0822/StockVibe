# StockVibe 메뉴별 UI 와이어프레임 (개선용)

기준 버전:
- 메인 대시보드 탭: `📊 시그널 / 🎯 시뮬레이션 / ⚙️ 최적화 / 🔄 데이터`
- 포트폴리오 탭: `📊 포트폴리오 현황 / 📈 거래 분석 / 📝 거래 이력 입력`

---

## 0) 공통 레이아웃 (Global)

```
┌──────────────────────────────────────────────────────────────────────┐
│ Header: 📊 StockVibe Pro | 현재 페이지명 | 상태/알림 뱃지             │
├───────────────┬──────────────────────────────────────────────────────┤
│ Left Sidebar  │ Main Content Area                                    │
│ - 메뉴 라디오 │ - 페이지별 핵심 기능                                  │
│ - (main일때)  │ - 상단 요약 KPI → 필터/입력 → 결과 테이블/차트        │
│   탭 선택      │ - 하단 액션(다운로드/공유/실행)                        │
└───────────────┴──────────────────────────────────────────────────────┘
```

사이드바 메뉴:
- 메인 대시보드
- 종목분석
- 포트폴리오
- 설정

## 1) 메인 대시보드 > 📊 시그널

```
┌ Main: 📊 시그널 ─────────────────────────────────────────────────────┐
│ [KPI 카드행] 기준일 | 코스피 상태 | 신호수(BUY/SELL) | Top Picks      │
│ ──────────────────────────────────────────────────────────────────── │
│ [보기 전환] (📊테이블 | 📋상세)                                      │
│ [결과 영역] 종목 테이블/상세카드 + 상위 시그널 칩                    │
│ ──────────────────────────────────────────────────────────────────── │
│ [액션] 카카오 공유/전송                                               │
└──────────────────────────────────────────────────────────────────────┘
```

개선 포인트(UX):
- KPI 카드 클릭 시 결과 테이블 필터 연동
- 칩 클릭 시 스크롤 고정(해당 종목 위치 하이라이트)
- 테이블/상세 뷰 상태를 URL 파라미터로 동기화

---

## 2) 메인 대시보드 > 🎯 시뮬레이션

```
┌ Main: 🎯 시뮬레이션 ─────────────────────────────────────────────────┐
│ [모드 선택] 기본 | 종목별 일괄 테스트 | 연도별 성과 분석             │
│ ──────────────────────────────────────────────────────────────────── │
│ [백테스트 설정] 초기 자산 | 매수 금액 단위 | 일일 매수 한도            │
│ [분석 기간 설정] 시작일 ~ 종료일 (연도별 모드 제외)                  │
│ [거래량 파라미터] 분석기간/급등기준/추가매수 임계값                  │
│ ──────────────────────────────────────────────────────────────────── │
│ [실행 버튼 영역] 실행 / 초기화                                        │
│ [결과 영역]                                                           │
│  - 기본: 자산곡선 + 승률통계 + 거래내역                               │
│  - 일괄: 종목별 성과표 + 랭킹 + 추천필터                              │
│  - 연도별: 연도별 성과/일관성 + 다운로드                              │
└──────────────────────────────────────────────────────────────────────┘
```

개선 포인트(UX):
- 실행 전 예상 소요시간/데이터 커버리지 표시
- 실행 중 단계형 진행률(데이터 로드→시그널→백테스트)
- 결과 저장 슬롯(최근 3개 설정 비교)

---

## 3) 메인 대시보드 > ⚙️ 최적화

```
┌ Main: ⚙️ 최적화 ─────────────────────────────────────────────────────┐
│ [입력] 탐색 범위(파라미터/기간/제약조건)                             │
│ [실행] 최적화 시작                                                    │
│ ──────────────────────────────────────────────────────────────────── │
│ [결과] 최적 파라미터 요약 + 성과 지표                                 │
│ [액션] 파라미터 적용 / JSON 다운로드                                  │
└──────────────────────────────────────────────────────────────────────┘
```

개선 포인트(UX):
- 탐색공간 크기(조합 수) 사전 표시
- 최적값 외 Top N 후보도 함께 비교

## 4) 메인 대시보드 > 🔄 데이터

```
┌ Main: 🔄 데이터 ─────────────────────────────────────────────────────┐
│ [데이터 소스 상태] 가격/재무/뉴스 최신 시각                           │
│ [작업] 수집/갱신/캐시 초기화                                           │

└──────────────────────────────────────────────────────────────────────┘
```

개선 포인트(UX):
- 실패 로그를 원인별(네트워크/파싱/파일) 태깅
- 데이터별 마지막 정상 수집 스냅샷 제공

## 5) 종목분석

```
┌ Page: 종목분석 ──────────────────────────────────────────────────────┐
│ [종목 선택] 코드/이름 검색                                             │
│ [요약] 현재가/등락률/거래량/핵심 재무                                  │
│ [탭] 차트 | 뉴스 | 시그널 근거 | AI 코멘트                             │
│ [액션] 관심종목 추가/비교로 보내기                                     │
└──────────────────────────────────────────────────────────────────────┘
```

개선 포인트(UX):
- ‘왜 BUY/SELL인지’ 근거를 카드형으로 고정 노출
- 뉴스 긍부정과 가격 움직임의 시계열 동시 표시

## 6) 포트폴리오

### 6-1) 📊 포트폴리오 현황
```
┌ Portfolio: 현황 ─────────────────────────────────────────────────────┐
│ [요약 KPI] 총자산 | 평가손익 | 수익률 | 보유종목수                      │
│ [보유목록] 종목/평단/수량/평가손익/비중                                 │
│ [액션] 초기화(보호확인)                                                  │
└──────────────────────────────────────────────────────────────────────┘
```

### 6-2) 📈 거래 분석
```
┌ Portfolio: 거래 분석 ─────────────────────────────────────────────────┐
│ [요약 KPI] 총 거래수 | 승률 | 평균수익률 | 총 실현손익                  │
│ [상세] 매도거래 테이블 + 중복거래 제거 안내                            │
│ [액션] 새로고침 / 전체 초기화                                            │
└──────────────────────────────────────────────────────────────────────┘
```

### 6-3) 📝 거래 이력 입력
```
┌ Portfolio: 거래 이력 입력 ────────────────────────────────────────────┐
│ [입력] 키움 체결알림 텍스트 + 거래 날짜                                 │
│ [중간결과] 파싱된 거래 미리보기                                          │
│ [실행] 포트폴리오 반영                                                   │
│ [결과] 반영 성공/오류 메시지 + 로그 저장 안내                           │
└──────────────────────────────────────────────────────────────────────┘
```

개선 포인트(UX):
- 파싱 오류를 줄 단위 하이라이트로 표시
- 반영 전 ‘미리 검증(드라이런)’ 모드 제공

## 8) 우선 적용 추천 (와이어프레임 기반)

1. 시뮬레이션 실행 UX 표준화
- 실행 버튼 위치 고정 + 진행률 + 중단 버튼

2. 결과 영역 컴포넌트 공통화
- KPI 카드/필터/테이블/다운로드를 메뉴 간 동일 패턴으로 통일

3. 포트폴리오 입력 안정성 강화
- 드라이런 + 파싱 실패 행 강조 + 중복 규칙 설명 UI

4. 상태 가시성 강화
- 데이터 최신 시각, 캐시 상태, 마지막 성공 실행 정보 공통 표시

## 10) 현재 프로젝트 소스 구조 (2026-02-28 기준)

### 10-1) 루트 구조(핵심)

```text
StockVibe/
├─ streamlit_app.py                # 앱 엔트리포인트
├─ app/                            # UI/도메인 로직 핵심 패키지
├─ data/                           # 런타임 데이터/캐시/포트폴리오 저장
├─ docs/                           # 기능/가이드/와이어프레임 문서
├─ tests/                          # pytest 기반 테스트
├─ *.py (루트 분석 모듈들)         # AI/크롤링/지표/최적화/유틸
├─ requirements.txt
├─ .streamlit/
├─ .venv/, .venv_gpu/
└─ __pycache__/
```

### 10-2) app/ 패키지

```text
app/
├─ phase4_ui.py                    # 사이드바 메뉴/페이지 라우팅 허브
```
