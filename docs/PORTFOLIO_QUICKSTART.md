# 💼 포트폴리오 관리 - 빠른 시작 가이드

## 🚀 종목 추가 방법 (개선됨!)

### 방법 1: 검색으로 추가 (추천!) 🔍

1. **포트폴리오** 메뉴 → **➕ 종목 추가** 탭 이동
2. 검색창에 종목명 또는 종목코드 입력
   - 예: "삼성전자", "005930", "SK하이닉스" 등
3. 검색 결과에서 원하는 종목 찾기
4. **➕ 추가** 버튼 클릭
5. 보유 수량과 평균 매입단가 입력
6. 매수일 선택
7. **➕ 포트폴리오에 추가** 버튼 클릭

### 방법 2: 직접 입력

1. **종목 추가** 탭에서 입력 폼 사용
2. 종목코드와 종목명 직접 입력
3. 수량, 매입단가, 매수일 입력
4. 추가 버튼 클릭

## 💡 사용 팁

### 평균 매입단가 계산
여러 번 매수한 경우:
```
예시:
1차: 10주 @ 70,000원
2차: 5주 @ 80,000원

평균단가 = (10×70,000 + 5×80,000) / 15
        = (700,000 + 400,000) / 15
        = 73,333원
```

### 매도 타이밍 활용
- **초록색 알림**: 수익이 좋으니 일부 매도 고려
- **노란색 알림**: 주의 깊게 관찰
- **빨간색 알림**: 손절 또는 즉시 조치 필요

### 자동 데이터 수집
- 포트폴리오 탭을 열면 자동으로 최신 가격 조회
- 진행률 표시로 수집 현황 확인 가능
