# 📊 StockVibe Pro - Phase 4 기능 가이드

## 🎉 새로운 기능 소개

Phase 4에서는 StockVibe를 **전문가급 투자 분석 플랫폼**으로 업그레이드했습니다!

---

## 🆕 추가된 기능

### 1. 💼 포트폴리오 관리
**위치**: 사이드바 → 포트폴리오

#### 주요 기능
- **보유 종목 관리**
  - 매수 내역 등록 (종목, 수량, 평균단가)
  - 실시간 평가손익 계산
  - 수익률 자동 추적
  - 종목별 상세 분석

- **관심 종목 관리**
  - 즐겨찾기 종목 저장
  - 빠른 조회 및 모니터링

- **포트폴리오 분석**
  - 총 평가금액/손익 요약
  - 종목별 비중 원형 차트
  - 섹터별 분산 분석

#### 사용 방법
```
1. '포트폴리오' 메뉴 선택
2. '종목 추가' 탭에서 보유/관심 종목 등록
3. '보유 종목' 탭에서 실시간 손익 확인
```

---

### 2. 📈 백테스팅 & 정확도 검증
**위치**: 사이드바 → 백테스팅

#### 주요 기능
- **전략 백테스팅**
  - 골든크로스 전략 (MA5/MA20)
  - RSI 과매수/과매도 전략 (30/70, 20/80)
  - 승률, 수익률, 거래 횟수 통계
  - 거래 내역 상세 분석

- **AI 예측 정확도 추적**
  - 1주일 후 실제 결과와 비교
  - 예측 성공률 통계
  - 예측 이력 추이 분석

- **전략 성과 비교**
  - 여러 전략의 수익률 비교
  - 최적 전략 추천

#### 사용 방법
```
1. '백테스팅' 메뉴 선택
2. 종목코드 입력
3. 기간 및 전략 선택
4. '백테스트 실행' 클릭
5. 결과 분석 (수익률, 승률, 거래 내역)
```

---

### 3. 🔔 실시간 알림 관리
**위치**: 사이드바 → 알림 관리

#### 알림 유형
1. **가격 알림**
   - 목표가 도달 시 알림
   - 이상/이하 설정 가능

2. **등락률 알림**
   - 급등/급락 감지 (기준% 설정)
   - 단기 변동성 추적

3. **뉴스 키워드 알림**
   - 특정 키워드 포함 뉴스 감지
   - 예: "실적", "배당", "인수합병"

#### 사용 방법
```
1. '알림 관리' 메뉴 선택
2. '알림 추가' 탭에서 설정
3. '활성 알림' 탭에서 관리
4. '발동 이력' 탭에서 확인
```

---

### 4. 🔍 종목 비교 분석
**위치**: 사이드바 → 종목 비교

#### 주요 기능
- **다종목 동시 비교**
  - 가격, 등락률, 거래량
  - PER, PBR, ROE 등 재무지표
  - AI 점수 비교

- **가격 추이 비교 차트**
  - 정규화 차트 (시작점 100 기준)
  - 수익률 비교 시각화

- **레이더 차트**
  - 다차원 비교 (재무/기술/AI 등)
  - 종목 강점/약점 파악

#### 사용 방법
```
1. '종목 비교' 메뉴 선택
2. 종목코드 입력 (쉼표로 구분)
   예: 005930,000660,035420
3. '비교 분석' 클릭
4. 테이블 및 차트로 결과 확인
```

---

### 5. 🌐 섹터 분석
**위치**: 사이드바 → 섹터 분석

#### 주요 기능
- **섹터별 수익률 분석**
  - 반도체, IT, 자동차, 금융 등
  - 평균 등락률 계산
  - 상승/하락 종목 수

- **섹터 히트맵**
  - 색상으로 수익률 표현
  - 섹터 강세/약세 한눈에 파악

- **섹터별 상위 종목**
  - 각 섹터 Top 3 종목
  - 실시간 등락률 및 AI 점수

- **섹터 로테이션 감지**
  - 자금 이동 감지
  - 투자 타이밍 포착

#### 사용 방법
```
1. '섹터 분석' 메뉴 선택
2. '섹터 분석 실행' 클릭
3. KOSPI 200 데이터 자동 수집
4. 섹터별 분석 결과 확인
```

---

### 6. 📊 고급 차트 & 패턴 인식
**위치**: 사이드바 → 고급 차트

#### 주요 기능
- **캔들 패턴 자동 인식**
  - 도지 (Doji): 추세 전환 신호
  - 망치형 (Hammer): 매수 신호
  - 유성형 (Shooting Star): 매도 신호
  - 포용형 (Engulfing): 강력한 반전 신호

- **거래량 분석**
  - 가격-거래량 결합 차트
  - 거래량 급증 감지
  - 거래량 프로파일 (가격대별 거래량)
  - 거래량 추세 분석

- **상관관계 분석**
  - 종목 간 상관계수 계산
  - 히트맵 시각화
  - 유사 종목 찾기

#### 사용 방법
```
1. '고급 차트' 메뉴 선택
2. 종목코드 및 기간 선택
3. '차트 생성' 클릭
4. 패턴/거래량 분석 결과 확인
```

### 7. 📥 데이터 내보내기 & 리포트
**위치**: 사이드바 → 데이터 내보내기

#### 주요 기능
- **데이터 내보내기**
  - Excel 형식 (.xlsx)
  - CSV 형식 (.csv)
  - KOSPI 200 전체 데이터

- **자동 리포트 생성**
  - 종목 분석 리포트 (Markdown)
  - 포트폴리오 리포트
  - 종목 비교 리포트

- **차트 이미지 저장**
  - PNG/JPEG 이미지
  - SVG 벡터 이미지
  - 인터랙티브 HTML

#### 사용 방법
```
1. '데이터 내보내기' 메뉴 선택
2. 내보내기 유형 선택
3. 다운로드 버튼 클릭
4. 로컬에 저장
```

### 8. ⚙️ 개인화 설정
**위치**: 사이드바 → 설정

#### 설정 항목
- **화면 설정**
  - 테마 (Light/Dark/Blue)
  - 차트 높이
  - 거래량 표시 여부

- **기본값 설정**
  - 기본 조회 기간
  - 차트 타입
  - 1위 종목 자동 펼치기

- **알림 설정**
  - 알림 활성화
  - 소리 알림

- **분석 설정**
  - AI 예측 표시
  - 기술적 지표 표시
  - 뉴스 표시

- **고급 설정**
  - 캐싱 활성화
  - 디버그 정보
  - 설정 초기화

#### 사용 방법
```
1. '설정' 메뉴 선택
2. 원하는 설정 변경
3. '저장' 버튼 클릭
4. 변경사항 즉시 적용
```

## 📊 데이터 저장 위치

모든 사용자 데이터는 `data/` 폴더에 JSON 형식으로 저장됩니다:

- **portfolio.json**: 보유 종목 정보
- **watchlist.json**: 관심 종목 목록
- **alerts.json**: 알림 설정

- **user_settings.json**: 사용자 설정

**백업 권장**: 중요한 데이터는 정기적으로 백업하세요!

## 🔧 고급 기능

### 백테스팅 API 활용
```python
from app.backtesting import BacktestingEngine

engine = BacktestingEngine()
result = engine.backtest_technical_strategy(price_df, 'golden_cross')
print(f"수익률: {result['total_return']:.2f}%")
print(f"승률: {result['win_rate']:.1f}%")
```

### 포트폴리오 프로그래밍 접근
```python
from app.portfolio import PortfolioManager

mgr = PortfolioManager()
mgr.add_to_portfolio('005930', '삼성전자', 10, 70000)
summary = mgr.get_portfolio_summary(current_prices)
```

### 알림 프로그래밍 설정
```python
from app.alerts import AlertManager

alert_mgr = AlertManager()
alert_mgr.add_price_alert('005930', '삼성전자', 'above', 75000, 70000)
```

## 🆘 문제 해결

### 데이터가 표시되지 않을 때
1. 인터넷 연결 확인
2. 종목코드 정확성 확인
3. '데이터 새로고침' 버튼 클릭

### 차트가 로딩되지 않을 때
1. 브라우저 캐시 삭제
2. 페이지 새로고침 (F5)

### 알림이 작동하지 않을 때
1. 설정에서 알림 활성화 확인
2. 알림 조건 재확인
