# 📊 StockVibe Pro - Phase 4 기능 가이드

## 🎯 현재 메뉴 구조

현재 앱의 사이드바 메뉴는 아래 4개로 운영됩니다.

1. 🏠 메인 대시보드
2. 📈 종목분석
3. 💼 포트폴리오
4. ⚙️ 설정

---

## 1) 🏠 메인 대시보드

메인 대시보드는 탭 기반으로 구성됩니다.

- 📊 시그널
- 🎯 시뮬레이션
- ⚙️ 최적화
- 🔄 데이터

### 1-1. 📊 시그널
- 당일 기준 BUY/SELL 시그널 확인
- 종목별 테이블/상세 보기 전환
- 카카오 공유 및 CSV 내보내기

### 1-2. 🎯 시뮬레이션
- 모드 선택: 기본 / 종목별 일괄 테스트 / 연도별 성과 분석
- 백테스트 파라미터 입력(초기 자산, 매수 단위, 일일 매수 한도 등)
- 실행/초기화/중단 제어 및 최근 실행 설정 재사용

### 1-3. ⚙️ 최적화
- 탐색 범위(min/max/step) 기반 조합 생성
- 조합 수/예상 시간/제약 조건 사전 확인
- Top N 후보 비교, 파라미터 적용, CSV/JSON 내보내기

### 1-4. 🔄 데이터
- 데이터 최신 시각 확인
- 데이터 갱신/캐시 관련 작업 수행

---

## 2) 📈 종목분석

- 개별 종목 차트(캔들/거래량) 확인
- 신호 발생 이력과 기본 통계 확인
- 뉴스/재무 정보 연계 조회

---

## 3) 💼 포트폴리오

포트폴리오 메뉴는 3개 탭으로 구성됩니다.

1. 📊 포트폴리오 현황
2. 📈 거래 분석
3. 📝 거래 이력 입력

### 3-1. 📊 포트폴리오 현황
- 보유 종목/수량/평단/수익률 확인
- 종목 추가 및 기본 현황 관리

### 3-2. 📈 거래 분석
- 총 거래수/승률/평균수익률/실현손익 분석
- 매도 거래 상세 테이블 확인

### 3-3. 📝 거래 이력 입력
- 키움 체결 알림 텍스트 파싱
- 거래 내역 미리보기 후 포트폴리오 반영

---

## 4) ⚙️ 설정

- 테마, 표시 옵션 등 사용자 환경 설정
- 기본값 및 고급 설정 관리
