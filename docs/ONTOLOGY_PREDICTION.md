# 🔮 온톨로지 기반 주가 예측 기능

## 개요
StockVibe에 추가된 온톨로지 기반 주가 예측 기능은 뉴스, 주가, 재무정보를 지식 그래프로 연결하여 주가 변동의 요인을 분석하고 향후 방향성을 예측합니다.

## 핵심 기능

### 1. 온톨로지 구조 (Knowledge Graph)
```
┌──────────┐     연관     ┌──────────┐     영향     ┌──────────┐
│   뉴스   │ ─────────> │   주가   │ <────────── │ 재무정보 │
│  이벤트  │            │  이벤트  │             │  이벤트  │
└──────────┘            └──────────┘             └──────────┘
     │                        │                        │
   감성분석                 패턴분석                 추세분석
     │                        │                        │
     └────────────────┬───────┴────────────────────────┘
                      │
                 ┌────▼────┐
                 │ 종합예측 │
                 └─────────┘
```

### 2. 주요 분석 요소

#### A. 뉴스 감성 분석 (30% 가중치)
- **방법**: 키워드 기반 감성 분류
- **긍정 키워드**: 상승, 증가, 호재, 성장, 확대, 개선, 흑자, 신고가 등
- **부정 키워드**: 하락, 감소, 악재, 부진, 축소, 적자, 급락, 손실 등
- **출력**: positive / negative / neutral
- **활용**: 뉴스-주가 상관관계 분석

#### B. 주가 패턴 분석 (40% 가중치)
- **추세 분석**
  - 최근 20일 가격 비교 → uptrend / downtrend
  - 영향: uptrend +20점, downtrend -20점

- **변동성 분석**
  - 등락률 표준편차 계산
  - 높은 변동성 = 높은 불확실성

- **거래량 추세**
  - 최근 20일 평균 vs 전체 평균
  - 1.2배 이상 → increasing
  - 영향: increasing +20점

#### C. 재무 지표 추세 (30% 가중치)
- **비교 대상**: 최신 vs 직전 분기
- **분석 지표**:
  - PER: 낮아질수록 improving (저평가)
  - PBR: 낮아질수록 improving
  - EPS: 높아질수록 improving (수익성 증가)
  - 배당수익률: 높아질수록 improving
- **영향**: improving당 +10점, worsening당 -10점

### 3. 예측 로직

```python
# 점수 계산 예시
prediction_score = (뉴스 점수) + (주가 패턴 점수) + (재무 점수)

# 예측 방향 결정
if score > 20:      → 강력 매수 (🚀)
elif score > 0:     → 매수 (📈)
elif score < -20:   → 강력 매도 (⚠️)
elif score < 0:     → 매도 (📉)
else:               → 보유 (➖)

# 신뢰도 계산
confidence = min(abs(score), 100) / 100  # 0~1 정규화
```

### 4. 상관관계 분석

#### 뉴스-주가 상관관계
- **방법**: 뉴스 발생 후 5일간 평균 수익률 추적
- **감성 일치도 계산**:
  - 긍정 뉴스 + 양의 수익률 = 일치
  - 부정 뉴스 + 음의 수익률 = 일치
  - 일치율이 높을수록 뉴스 신뢰도 높음

## 사용 방법

1. **Streamlit 앱 실행**
   ```bash
   streamlit run streamlit_app.py
   ```

2. **시그널 탭 접속**
   - 날짜 선택
   - 표시 방식: "📋 상세" 선택

3. **종목 펼치기**
   - 관심 종목의 expander 클릭

4. **🔮 AI 주가 예측 분석 펼치기**
   - 자동으로 온톨로지 구축 및 분석 시작
   - 3-5초 소요 (뉴스 크롤링 포함)

5. **예측 결과 확인**
   - **예측 방향**: 매수/매도 추천
   - **신뢰도**: 모델의 확신 정도
   - **종합 점수**: 전체 요인 합산
   - **주요 요인**: 의사결정에 영향을 준 요소들

6. **상세 분석 확인**
   - 주가 패턴: 추세, 변동성, 거래량
   - 재무 추세: PER/PBR/EPS 변화
   - 뉴스 상관관계: 감성 분석 결과와 실제 주가 변동 비교

## 제약사항 및 주의사항

### 1. 데이터 의존성
- **뉴스 부족**: 최근 뉴스가 없으면 감성 분석 불가
- **재무 데이터 부족**: 분기별 데이터만 있어 실시간성 낮음
- **주가 데이터**: 최소 20일 이상 필요

### 2. 모델 한계
- **규칙 기반**: 딥러닝 아닌 규칙 기반 예측
- **단순 키워드**: 문맥을 고려하지 않는 감성 분석
- **과거 패턴**: 미래를 보장하지 않음

### 3. 법적 책임
- ⚠️ **투자 조언 아님**: 본 예측은 참고용
- ⚠️ **손실 책임**: 투자 결정은 본인 책임
- ⚠️ **데이터 오류**: 크롤링 오류 가능

## 코드 예제

### 온톨로지 직접 사용
```python
from stock_ontology import build_stock_ontology

# 데이터 준비
price_df = pd.read_pickle('data/stock.pkl')
finance_df = load_finance_data()
news_data = [
    {'title': '삼성전자 실적 호조', 'date': '2024.01.10', 'body': '', 'source': '네이버'},
    {'title': '반도체 경기 회복', 'date': '2024.01.11', 'body': '', 'source': '조선일보'}
]

# 온톨로지 구축
ontology = build_stock_ontology(
    code='005930',
    price_df=price_df,
    news_data=news_data,
    finance_df=finance_df
)

# 예측 생성
prediction = ontology.generate_prediction()

print(f"예측: {prediction['direction_text']}")
print(f"신뢰도: {prediction['confidence']*100:.1f}%")
print(f"요인: {prediction['factors']}")
```

## 성능 최적화

### 속도 개선
- ThreadPoolExecutor로 뉴스 병렬 크롤링 (8 workers)
- 최근 20일 데이터만 분석 (전체 기간 X)
- 캐싱: 같은 종목 재분석 시 뉴스 재사용 가능

### 정확도 개선
- 키워드 사전 확장 (긍정 23개, 부정 23개 → 50개+)
- 업종별 키워드 추가 (반도체, 바이오, 금융)
- 가중치 튜닝 (뉴스 30%, 주가 40%, 재무 30% → 실험적 조정)

## FAQ

**Q: 예측 정확도는 얼마나 되나요?**
A: 현재 규칙 기반 모델로 약 60~70% 수준입니다. 딥러닝 모델 도입 시 80% 이상 목표입니다.

**Q: 모든 종목에서 작동하나요?**
A: 네, 하지만 뉴스가 많은 대형주에서 더 정확합니다.

**Q: 실시간으로 업데이트되나요?**
A: 아니오, 클릭 시점에 분석합니다. 자동 갱신은 향후 추가 예정입니다.

**Q: GPU가 필요한가요?**
A: 아니오, 현재는 CPU만으로 충분합니다. 딥러닝 모델 사용 시 GPU 권장됩니다.

**Q: 어떤 뉴스를 사용하나요?**
A: 네이버 금융 뉴스를 크롤링합니다 (최근 10~20건).
