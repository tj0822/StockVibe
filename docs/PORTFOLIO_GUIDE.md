# 💼 포트폴리오 관리 & 매도 타이밍 가이드

## 📊 개요

StockVibe Pro의 포트폴리오 관리 시스템은 보유 종목의 수익률을 실시간으로 추적하고, **자동으로 매도 타이밍을 알려주는** 기능을 제공합니다.

---

## ✨ 주요 기능

### 1. 보유 종목 관리
- 종목코드, 종목명, 수량, 평균 매입단가 입력
- 실시간 현재가 자동 조회
- 평가금액 및 평가손익 자동 계산
- 수익률 자동 계산 (%)

### 2. 매도 타이밍 자동 알림 🔔
시스템이 자동으로 다음 조건을 감지하여 알림을 제공합니다:

#### ✅ 수익 실현 신호
- **목표 수익률 20% 달성**: 부분 매도 고려
- **고수익 50% 달성**: 수익 실현 권장 (🎯 표시)

#### ⚠️ 손절 신호
- **손실 -10% 도달**: 손절 검토 필요
- **큰 손실 -20% 도달**: 즉시 손절 권장 (🚨 표시)

#### 📊 기술적 신호
- **데드크로스 발생** (MA5 < MA20): 하락 추세 시작
- **골든크로스 발생** (MA5 > MA20): 반등 기대

## 🚀 사용 방법

### 1단계: 보유 종목 추가

```
📍 메뉴: 사이드바 → 💼 포트폴리오 → ➕ 종목 추가 탭

1. 종목코드 입력 (예: 005930)
2. 종목명 입력 (예: 삼성전자)
3. 보유 수량 입력 (예: 10주)
4. 평균 매입단가 입력 (예: 70,000원)
5. "➕ 포트폴리오에 추가" 버튼 클릭
```

### 2단계: 실시간 수익률 확인

```
📍 메뉴: 사이드바 → 💼 포트폴리오 → 📊 보유 종목 탭

자동으로 표시되는 정보:
- 총 평가금액: 현재 보유 종목의 총 가치
- 총 평가손익: 수익/손실 금액 (원)
- 수익률: 전체 포트폴리오 수익률 (%)
- 보유 종목 수: 보유 중인 종목 개수
```

### 3단계: 매도 타이밍 알림 확인

```
📍 위치: 보유 종목 탭 상단 "🔔 매도 타이밍 알림" 섹션

알림 종류:
🟢 초록색 박스: 수익 실현 권장
🟡 노란색 박스: 부분 매도 고려
🔴 빨간색 박스: 손절 권장

각 알림에는 다음 정보가 포함됩니다:
- 현재 수익률
- 수익금액 (원)
- 보유 기간 (일)
- 권장 행동
- 구체적 신호 (골든크로스, 데드크로스 등)
```

### 4단계: 종목별 상세 분석

```
📍 위치: "📊 종목별 상세 현황" 섹션

각 종목을 클릭하면:
- 보유수량, 평균단가, 현재가, 평가금액, 평가손익
- 매도 타이밍 분석
  - 보유 기간
  - 권장 행동
  - 구체적 신호 목록
- 빠른 매도 버튼
```

## 📊 매도 타이밍 알고리즘

### 신호 판단 로직

```python
# 1. 수익률 기준
if 수익률 >= 50%:
    신호 = "🎯 수익 실현"
elif 수익률 >= 20%:
    신호 = "✅ 부분 매도 고려"

# 2. 손실 기준
if 수익률 <= -20%:
    신호 = "🚨 즉시 손절"
elif 수익률 <= -10%:
    신호 = "⚠️ 손절 검토"

# 3. 기술적 분석
if 데드크로스 발생 and 수익률 > 0:
    신호 = "📉 부분 매도 고려"
elif 골든크로스 발생 and 수익률 < 0:
    신호 = "📈 추가 관찰"
```

## 🎯 전략 가이드

### 1. 분할 매도 전략
```
수익률 +20%: 30% 매도 (수익 일부 확정)
수익률 +30%: 추가 30% 매도
수익률 +50%: 나머지 전량 매도
```

### 2. 손절 전략
```
손실 -10%: 관찰 (추가 하락 시 매도 준비)
손실 -15%: 50% 손절 (손실 최소화)
손실 -20%: 전량 손절 (추가 손실 방지)
```

### 3. 기술적 신호 활용
```
데드크로스 + 수익 상태: 부분 매도로 수익 보호
골든크로스 + 손실 상태: 반등 기대하며 관찰
```

## 🔧 고급 기능

### 프로그래밍 방식 활용

```python
from app.portfolio import PortfolioManager

# 포트폴리오 매니저 생성
mgr = PortfolioManager()

# 종목 추가
mgr.add_to_portfolio('005930', '삼성전자', 10, 70000)

# 매도 타이밍 분석
analysis = mgr.analyze_sell_timing('005930', current_price=105000)
print(f"권장: {analysis['recommendation']}")
print(f"수익률: {analysis['profit_rate']:.2f}%")

# 모든 매도 신호 확인
sell_signals = mgr.get_all_sell_signals(current_prices)
for signal in sell_signals:
    print(f"{signal['name']}: {signal['recommendation']}")
```

## ❓ FAQ

### Q1: 매입단가는 어떻게 계산하나요?
**A**: 여러 번 매수한 경우 가중평균으로 자동 계산됩니다.
```
예: 
1차 매수: 10주 @ 70,000원
2차 매수: 5주 @ 80,000원
평균단가 = (10×70,000 + 5×80,000) / 15 = 73,333원
```

### Q2: 실제 매도는 어떻게 하나요?
**A**: StockVibe는 분석 도구입니다. 실제 매도는 증권사 앱/HTS에서 진행하세요.

### Q3: 여러 증권사 계좌를 통합 관리할 수 있나요?
**A**: 네, 모든 계좌의 보유 종목을 합산하여 입력하면 됩니다.

### Q4: 과거 매매 이력을 볼 수 있나요?
**A**: 현재는 현재 보유 종목만 관리됩니다. 향후 업데이트 예정입니다.
